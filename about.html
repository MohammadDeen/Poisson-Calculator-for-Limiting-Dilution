About

About this tool

A free, static, client-side Poisson calculator for designing limiting-dilution cloning experiments.

Author

Mohammad Deen Hayatu
Institute of Human Genetics, University Hospital Erlangen

Origin

Born out of a CRISPR project: after working through a limiting dilution by hand, I wanted a tool to take the weight of the calculations — seeding density, volumes, concentrations — off the bench, so the time goes to the real science.

Source code

This project is open source and runs entirely in your browser — there is no server and no tracking. View the code, file issues, or contribute on GitHub:

github.com/MohammadDeen/Poisson-Calculator-for-Limiting-Dilution
